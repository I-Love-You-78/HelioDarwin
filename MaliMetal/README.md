# MaliMetal (Experimental Research Skeleton)

This directory contains research prototypes and ICD interfaces implementing the `MTLDevice` protocol for Apple's `Metal.framework` over Mesa's `panvk` (Vulkan) for ARM Mali-G57 (Valhall).

Following the prior art of [darlinghq/indium](https://github.com/darlinghq/indium) and [darling-metal](https://github.com/darlinghq/darling-metal), this code explores bridging Metal state objects to Vulkan command buffers.

**Status:** Early architectural research prototype / skeleton (WIP).
